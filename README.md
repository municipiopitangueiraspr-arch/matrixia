

## Área autenticada

Após o login, a plataforma exibe um cabeçalho fixo compartilhado, com a marca MatrixIA, nome/e-mail e avatar do usuário. A página inicial apresenta cards clicáveis para as 11 áreas municipais e Governança. Nesta primeira entrega, os cards exibem popup informativo de módulo em preparação; as rotas e funcionalidades específicas serão conectadas na próxima etapa.
